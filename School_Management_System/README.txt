SCHOOL MANAGEMENT SYSTEM
=========================
Technology: PHP 8 + MySQL + Bootstrap 5
For XAMPP / localhost

INSTALL:
1. Extract this folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin and import database.sql
4. Open: http://localhost/school_management_system/
5. Login:
   Username: admin
   Password: admin123

Database name: school_management

The system includes:
- Admin login
- Dashboard
- Students CRUD
- Teachers
- Classes
- Subjects
- Attendance
- Exams/Results
- Fees
- Timetable
- Reports
